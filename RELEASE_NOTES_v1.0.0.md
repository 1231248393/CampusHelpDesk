# CampusHelpDesk v1.0.0

Initial public source release.

Includes:
- Separate React/Vite Student and Admin portals
- Flask REST API
- MySQL schema migrations
- JWT-authenticated student/admin API flows
- Complaint submission, tracking, status history and notifications
- Admin complaint operations and analytics
- Complaint-assistance module and backend checks
- Local setup and database upgrade documentation

This release archive excludes credentials, database dumps, backups, runtime logs, dependency directories and generated build output. Configure a local `backend/.env` before starting the application.
